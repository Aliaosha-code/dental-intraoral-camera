# Security

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities.

Send a private report to the maintainer through the repository's GitHub
security advisory feature:

<https://github.com/Aliaosha-code/dental-intraoral-camera/security/advisories/new>

Include a short description, reproduction steps, and the affected platform.

## Scope

This desktop application requests camera access locally through Electron.
No patient data or captured images are uploaded by the application itself.
